# Dzulfikar Azis Portfolio v4.6 — Desktop Hero Alignment

## Scope
Refinement patch for desktop/tablet hero section using the current mobile hero composition as the visual reference.

## Changes
- Reduced desktop hero headline scale slightly for better balance.
- Increased desktop hero title max-width so "BUILDING" is no longer visually clipped.
- Expanded hero text breathing room by increasing `.hero-copy` max width.
- Reduced portrait footprint on desktop and moved it slightly further right.
- Lightened portrait overlay gradient significantly so it no longer feels too dark or heavy.
- Reduced portrait interference with text block so the left-side heading remains fully readable.
- Kept mobile hero composition unchanged.
