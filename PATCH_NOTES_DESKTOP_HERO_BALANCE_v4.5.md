# Dzulfikar Azis Portfolio v4.5 — Desktop Hero Balance

Baseline: v4.4

## Scope
Desktop/tablet hero refinement only. Mobile hero treatment remains unchanged.

## Changes
- Reduced desktop hero headline scale slightly for a lighter visual balance.
- Reduced portrait width by roughly 20–25% compared with v4.4.
- Lowered portrait opacity and saturation so it behaves as a supporting background layer.
- Changed desktop portrait rendering to `object-fit: contain` and bottom anchoring so shirt and tie remain visible.
- Softened desktop portrait gradient/mask.
- Added more negative space between hero copy and portrait.
- Tablet portrait sizing adjusted consistently.

## Unchanged
- Mobile hero composition.
- Project Archive carousel behavior.
- Project ordering/content.
- About, Experience, Contact, and footer.
