# Dzulfikar Azis — KAR Labs Portfolio

Pure HTML/CSS/Vanilla JavaScript portfolio. No npm install or build step is required.

## Run with VS Code + Git Bash

1. Extract the ZIP.
2. Open the extracted folder in VS Code.
3. Open **Terminal > New Terminal**.
4. Make sure the terminal profile is **Git Bash**.
5. Run:

```bash
python -m http.server 8000
```

If `python` is not available on Windows, run:

```bash
py -m http.server 8000
```

6. Open:

```text
http://localhost:8000
```

Stop the server with `Ctrl + C`.
